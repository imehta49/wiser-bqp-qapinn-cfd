# Section 03 — Fourier-Feature Classical PINN

## Purpose

Angle-encoded variational quantum circuits naturally generate trigonometric feature maps. A classical Fourier-feature PINN is therefore an essential control for separating a generic spectral-feature advantage from effects specifically associated with the quantum circuit.

## Planned analysis

- fixed and trainable Fourier embeddings;
- frequency-bandwidth comparison;
- accuracy per parameter;
- gradient conditioning;
- generalization to held-out viscosity or time intervals.
