# AI Tool-Use Statement

Complete this file before final submission.

Suggested structure:

1. Tools used.
2. Tasks for which each tool was used.
3. Parts independently checked or rewritten by the team.
4. Tests used to validate generated code or text.
5. Confirmation that every team member can explain and defend the submitted implementation.

Example wording:

> AI assistance was used to draft portions of the initial software scaffold and documentation. The team independently reviewed, tested, modified, and validated the governing equations, automatic-differentiation implementation, reference solver, training procedure, numerical outputs, figures, and final conclusions.
